# AI Assistant

AI Assistant формирует черновик персонального учебного плана только по
обезличенной аналитике попыток. Имя, email, логин, ответы ученика, правильные
ответы и тексты заданий во внешний API не отправляются.

## Режим по умолчанию

Без дополнительных настроек используется локальный бесплатный mock:

```env
AI_PROVIDER=mock
```

Он подходит для разработки, автоматических тестов и проверки интерфейса.

## Подключение совместимого API

AI Assistant поддерживает серверный API, совместимый с методом
`POST /chat/completions`:

```env
AI_PROVIDER=openai-compatible
AI_API_BASE_URL=https://provider.example/v1
AI_API_KEY=replace_with_provider_api_key
AI_MODEL=provider-model-name
AI_REQUEST_TIMEOUT_MS=30000
```

Ключ хранится только в серверном `.env` и не имеет префикса `NEXT_PUBLIC_`,
поэтому не попадает в браузер. Внешний адрес должен использовать HTTPS;
HTTP разрешён только для локального тестового сервера.

После изменения `.env` перезапустите `npm run dev`.

## Защитный контур

1. Платформа строит и проверяет обезличенную аналитику.
2. Провайдер получает только этот объект и методическую инструкцию.
3. Ответ разбирается как JSON.
4. План проходит строгую схему, ограничения количества тем, дней и задач.
5. Неправильный или слишком большой ответ отклоняется.
6. При ошибке внешнего API используется резервный mock.
7. Неудачная внешняя генерация и успешный fallback сохраняются в истории
   раздельно.
8. Учитель видит, каким провайдером создан конкретный план.

План по-прежнему создаётся только вручную учителем, не показывается ученику и
не выдаёт задания автоматически.

## Проверка

```bash
npm run test:ai
npx tsc --noEmit
npm run lint
npm run build
```

Для проверки интерфейса на демонстрационных профилях:

```bash
npm run demo:ai:seed
npm run dev
```

Удаление только демонстрационных профилей:

```bash
npm run demo:ai:clear
```
