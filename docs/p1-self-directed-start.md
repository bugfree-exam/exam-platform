# P1: самостоятельный старт ученика

Ветка добавляет связный контур самостоятельной подготовки, не заменяя решения преподавателя автоматикой.

## Путь ученика

1. `/student/start` фиксирует цель в баллах, дату экзамена, реальный ресурс, длину занятия, удобные дни и самооценку старта.
2. `/student/diagnostic` проводит короткую стратифицированную входную диагностику по базовым, основным, продвинутым и экзаменационным блокам на опубликованных снимках задач. Знакомая задача не считается новым доказательством освоения.
3. После отправки диагностики строится `/student/route`: недельный маршрут по карте зависимостей с резервом на полные варианты. Если цель физически не помещается в доступный ресурс, маршрут показывает необходимость пересогласования, а не прячет перегрузку в последней неделе.
4. `/student/skills` объясняет состояния освоения и показывает, какие зависимости ещё не подтверждены.
5. Главная страница собирает старт, дедлайны, текущий этап маршрута, слабый навык, ошибки и вебинар в одну очередь «Сегодня». У карточки есть объяснение приоритета и действия «сделать», «на завтра», «уже умею — проверить», «нужна помощь».
6. `/student/calendar` объединяет маршрут, дедлайны и переносы. При изменении недельного ресурса создаётся новая версия маршрута; старая архивируется.
7. `/student/recovery` на семь дней ограничивает очередь одной недельной целью и максимум двумя короткими действиями в день. Причина, ресурс и дата проверки сохраняются для преподавателя.
8. `/student/errors` собирает неверные ответы диагностики, ДЗ, тренажёра и вариантов. Для закрытия ошибки ученик указывает причину, формулирует изменение и повторно получает верный ответ без преждевременного раскрытия решения. Контроль ставится через семь дней.

Глобальный маршрут и подтверждённый преподавателем «Ближайший спринт» показаны как разные сущности: первый объясняет путь до экзамена, второй — ближайшее педагогическое вмешательство.

## Сигналы преподавателю

Карточка ученика показывает цель и ресурс, состояние диагностики, наличие маршрута, активный режим восстановления и запросы «Нужна помощь» из очереди «Сегодня». После помощи преподаватель закрывает сигнал, не удаляя сам учебный пункт из очереди ученика.

## Данные и развёртывание

Изменения схемы находятся в миграции `20260814190000_p1_student_journey`. В production применять только:

```bash
npx prisma migrate deploy
```

Миграция не изменяет существующие попытки и не требует обязательного заполнения профиля для старых учеников: они увидят первый шаг онбординга на главной.
