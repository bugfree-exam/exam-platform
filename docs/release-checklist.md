# Production release checklist

Используйте этот список перед каждым обновлением VPS.

## 1. Локальная / CI-проверка

- `npm ci`
- `npx prisma validate`
- `npx prisma generate`
- `npm run lint`
- `npm run build`
- убедиться, что PR CI зелёный

## 2. Smoke test ученика

- вход ученика
- главная `/student` открывается
- блок «Сегодня» корректно различает: ожидается / <24 часов / просрочено
- onboarding-видео открывается, если задан `ONBOARDING_VIDEO_URL`
- ДЗ открывается и отправляется
- тренажёр сохраняет попытку
- вариант запускается, сохраняет ответы и завершается
- `/student/results` открывается для 30 / 90 дней / всего времени
- прогноз балла строится только по полным вариантам
- слабый номер ведёт в соответствующий тренажёр

## 3. Smoke test учителя

- главная учителя открывается
- создание/редактирование задания работает
- выдача ДЗ работает
- `/teacher/homeworks/review` не считает будущий дедлайн просрочкой
- создание/назначение варианта работает
- расписание вебинаров отображается у ученика

## 4. Telegram (если включён)

- `TELEGRAM_ENABLED=true` только после заполнения всех секретов
- ученик создаёт одноразовую ссылку и привязывает Telegram
- `/stop` отключает уведомления
- повторный `/start` включает их обратно
- ручной запуск reminder endpoint не создаёт дублей
- сданная работа не получает напоминание
- проверены `due soon` и `overdue` на тестовом ученике

## 5. VPS перед deploy

- `git status` чистый
- сохранить SHA текущего production
- запустить `scripts/backup.sh`
- запустить `scripts/test-restore.sh` на свежем backup
- проверить свободное место `df -h`
- Docker Compose config валиден

## 6. Deploy

- сначала собрать новые образы, не останавливая старый app
- выполнить `prisma migrate deploy` через сервис `migrate`
- только после успешной миграции пересоздать `app`
- проверить `/api/health`
- просмотреть последние логи app

## 7. После deploy

- повторить ключевой smoke test через production-домен
- проверить login ученика и учителя
- проверить «Сегодня», «Результаты», одно ДЗ и один вариант
- если включён Telegram — проверить webhook и один тестовый reminder run

Никогда не использовать в production `prisma migrate reset`, `docker compose down -v` или удаление PostgreSQL volume как способ отката.
